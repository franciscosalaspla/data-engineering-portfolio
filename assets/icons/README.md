# Iconos del portafolio

Los iconos de Azure, AWS, Python y DuckDB proceden de [Devicon](https://github.com/devicons/devicon), bajo licencia MIT. Los originales se conservan sin cambios; la variante `aws-dark.svg` usa letras blancas para mantener la legibilidad sobre fondo oscuro. La licencia se incluye en `LICENSE.devicon`.

Fuentes consultadas el 20 de octubre de 2026:

- [Azure](https://github.com/devicons/devicon/blob/master/icons/azure/azure-original.svg).
- [AWS](https://github.com/devicons/devicon/blob/master/icons/amazonwebservices/amazonwebservices-original-wordmark.svg).
- [Python](https://github.com/devicons/devicon/blob/master/icons/python/python-original.svg).
- [DuckDB](https://github.com/devicons/devicon/blob/master/icons/duckdb/duckdb-original.svg).

Los iconos de [Databricks](../../23-azure-adf-databricks-bank-fx/docs/images/icons/databricks.svg) y [Azure Data Factory](../../23-azure-adf-databricks-bank-fx/docs/images/icons/data-factory.svg) reutilizan los recursos ya incluidos en el proyecto Azure.
