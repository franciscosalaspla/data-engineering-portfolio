# Recursos visuales del Data Lake

- `data-lake-portada-light.svg` y `data-lake-portada-dark.svg`: portada con el problema, el recorrido y las cifras documentadas.
- `arquitectura-data-lake-light.svg` y `arquitectura-data-lake-dark.svg`: arquitectura vertical de la implementación local, con cuarentena lateral y equivalencias AWS.
- Los SVG son las fuentes editables y conservan el texto como texto, para poder corregir cifras y etiquetas.
- Los gráficos ilustran el flujo del proyecto; no son capturas de una ejecución.

Las cifras y su origen están en [resultados-documentados.md](../docs/resultados-documentados.md).

Los iconos de Python, DuckDB y AWS proceden de los [recursos del portafolio](../../assets/icons/README.md), con licencia MIT incluida allí. Se incrustan en los SVG para evitar dependencias de carga externas.

La marca personal de alien reutiliza el PNG transparente incluido en la [fuente de arquitectura Azure](../../23-azure-adf-databricks-bank-fx/docs/images/arquitectura-azure-source.html), con opacidad del 50 % en la esquina inferior derecha.

La imagen referencial `aws-cloud-development-services-by-vizsphere.jpeg` se conserva como recurso histórico y ya no se usa como portada del README.
